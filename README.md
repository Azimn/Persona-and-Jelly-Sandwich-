# Gelatinblob Sidecar

Version 0.11 is the current persona-conditioned sidecar runtime.

The canonical lifecycle is:

```text
objective observation
-> persona-conditioned attention and appraisal
-> current self-state + retrieved history
-> situated interpretation
-> active pressures and conflicts
-> candidate conduct generation
-> persona-weighted viability forecast
-> host legal-action filter
-> chosen conduct
-> renderer packet
-> expression
-> delivered world action
-> observed consequence
-> persona-shaped learning
```

See `COGNITIVE_GRAPH.md`, `RUNTIME_COGNITION.md`, and `DEPLOYMENT.md`.
